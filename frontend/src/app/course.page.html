Run it on Windows

1. Install and start

Use Node.js 24 LTS and Python 3.12 or newer. Start in Lesson 0 and keep the terminal in this new application folder. Setup creates an independent .venv and installs both stacks.

Open http://localhost:5200. The API runs on port 8600. Stop both with Ctrl+C. You can also use dev:api and dev:web in separate terminals.

2. Configure the private backend

Replace the placeholder with your Anthropic API key. Leave CLAUDE_MODEL empty for the SDK default. Turns accept integers 1–10. Process environment overrides this backend’s file. Restart FastAPI after editing; health reports key presence rather than authenticated readiness.

The frontend has no secret .env. Its public frontend/public/config.json contains only an API URL:

3. Package with Capacitor

Capacitor packages the Angular production build. Android needs Android Studio, its SDK and the JDK required by Capacitor 8. iOS compilation needs macOS and Xcode. Opening native IDEs is an explicit command; no store upload or signing is performed automatically.

A phone’s localhost points to the phone. Set API_HOST=0.0.0.0 and use your PC’s LAN IP in public config.json, or use an HTTPS development API. An Android emulator can use http://10.0.2.2:8600. HTTPS pages/native WebViews may block an HTTP API; use HTTPS, or a narrowly scoped development transport exception. Rebuild and sync after changing config.json. Allow the matching Capacitor/browser origin and local firewall ports.

4. Verify and build

Use FastAPI’s served frontend for a single-server web preview. Keep browser/native configuration public, use HTTPS and add authentication and cost/rate limits before exposing the paid-inference API publicly. CORS is not authentication.
